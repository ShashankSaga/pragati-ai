# Pragati AI
A simple AI-themed web UI built with HTML, CSS, and JavaScript.

## Features
- Responsive layout (HTML + CSS)
- Interactive JS logic in `script.js`
- Clean, deployable static site (GitHub Pages-ready)

## Run locally
Just open `index.html` in a browser, or use a local server (e.g., VS Code Live Server).
